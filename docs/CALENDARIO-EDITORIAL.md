# Calendario editorial: ocho semanas

Criterios para ordenar: **utilidad** para quien empieza, **dificultad** de hacerlo bien y **esfuerzo** (incluida la verificación de fuentes). No se usan volúmenes de búsqueda ni previsiones de tráfico porque no se han medido; cuando haya datos de Search Console, se reordenará con ellos.

Cada pieza nueva responde a una duda real, enlaza a la ruta inicial y a una herramienta, y pasa por `npm run check:content` y por revisión humana antes de publicarse.
